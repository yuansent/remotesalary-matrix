## 具体缺陷与复现

### Nomad：阻断销售

原文件哈希及清单见 `asset-inventory.json`，单元格原文见 `workbook-cells.json`，独立日期计算见 `independent-day-counts.json`。本轮未修改 XLSX/DOCX，也未运行 Excel 计算引擎；以下公式结论来自实际 XLSX XML 与独立日期计算，不能表述为已在 Excel 实测。

1. 工作表一 E5 是字符串 `183 Days`，F5 是 `E5-D5`。以普通电子表格算术应产生类型错误，不能用于计算剩余天数。
2. B5 的国家选择未被 D5 使用；D5 是 `SUM(E9:E30)`，把各国旅行混加。样例所有国家排除入境日共 351 天，而 Spain 两段仅 164 天；若首尾均计入是 166 天。G5 却按总数输出 TAX RESIDENT TRIGGERED。此错误无需判断任何税法即可成立。
3. 日期相减不包含入境日，同日为零；没有说明计日约定，也没有逆序/重叠/跨年窗口约束。
4. 预算表 `F4=(C4*(1-E4))-D4`，C4 为签证收入门槛而非用户收入。Spain 行按 2600、24%、1800 输出的 176 不代表买家节余。缺少实际收入输入。
5. 输出 SAFE & COMPLIANT、183 天税务居民结论及缺少来源的税率/生活费，不应作为税务判断。
6. 三份通用英语 DOCX 不是 25+ 国清单、当地语言模板或国家定制签证包；ZIP 没有网页承诺的 PDF。文档默认固定雇佣、保证收入、附件已齐等，用户照填可能作出不实声明。合同示例未经相关辖区专业复核。
7. 旧 `generate_pro_assets.py` 仍有诱导法律合规结论，且能覆盖当前资产；已在任何导入/写入之前显式阻断执行，保留源码供追溯。

实际商品是一个 Markdown 文件。正文承诺 25 jurisdictions，国家小节是 Poland、Romania、Brazil、India、Argentina/Colombia：共六国、五个小节。没有逐国完整交付与来源链。55–75% 节省、合同可执行性、人格权处理及分类风险等断言没有足够支持；合同措辞不能决定实际雇佣关系。
